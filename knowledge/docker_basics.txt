Основные команды Docker:
- docker ps: список запущенных контейнеров.
- docker images: список загруженных образов.
- docker logs -f [ID]: просмотр логов контейнера в реальном времени.
- docker exec -it [ID] bash: зайти внутрь работающего контейнера.
- docker system prune -a: полная очистка неиспользуемых образов и контейнеров (освобождает место).

Docker Compose:
- docker-compose up -d: запуск проекта в фоновом режиме.
- docker-compose down: остановка и удаление контейнеров проекта.
- docker-compose restart [service]: перезапуск конкретного сервиса.
