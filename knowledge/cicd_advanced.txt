Методология CI/CD:
- CI (Continuous Integration): Проверка кода на каждом коммите. Обязательные этапы: Linting, Unit-tests, SAST (статический анализ безопасности).
- CD (Continuous Deployment): Автоматический деплой в продакшн после успешных тестов.

GitLab CI Best Practices:
- Использовать 'stages' для логического разделения: build, test, deploy.
- 'cache' используется для ускорения сборки (например, папка node_modules).
- 'artifacts' передают результаты сборки между стадиями.
- Правило 'only' или 'rules' ограничивает запуск пайплайнов только для веток master/main.

Стратегии деплоя:
- Blue-Green: Два одинаковых окружения, переключение трафика через балансировщик.
- Canary: Деплой новой версии на 5-10% пользователей для проверки стабильности.
- Rolling Update: Постепенная замена старых подов/контейнеров на новые.
